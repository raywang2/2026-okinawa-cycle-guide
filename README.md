# 2026 Okinawa Cycle Guide

5-day Okinawa main-island cycling guide with route planning, Poké Lid collection points, cultural stops, preparation checklist, and GPX route seeds.

## Website
This repository is intended for GitHub Pages. The site entry point is `index.html`.

## GPX note
Files in `routes/` are waypoint route seeds, not verified turn-by-turn tracks. Re-route them in Garmin Connect, Komoot, Ride with GPS, Strava Routes, or another cycling router and verify current road/bicycle access before riding.

## Safety
Check current Okinawa road rules, closures, weather, and attraction access before departure.
